DERMADESK - SIMPLE JAVA SWING PROTOTYPE

REQUIREMENT
- Java JDK 17 or newer recommended
- Apache NetBeans or another Java IDE

OPEN IN APACHE NETBEANS
1. Open NetBeans.
2. Select File > New Project > Java with Ant > Java Application.
3. Name the project DermaDesk.
4. Create the project. If NetBeans creates Main.java, you can delete it.
5. Right-click Source Packages > New > Java Class.
6. Name the class DermaDeskApp.
7. Open DermaDeskApp.java from this ZIP, copy all its code, and paste it into the NetBeans class.
8. Run the file. The main method is inside DermaDeskApp.

DEMO FEATURES
- Customer and clinic staff entry screens
- Sample dermatology services with prices and durations
- Customer appointment booking
- Checks for overlapping active appointments
- Customer appointment history and status
- Staff can confirm, reschedule, reject, and cancel appointments
- Staff can add services and change service availability

IMPORTANT LIMITATION
This is a simple learning prototype. Appointment and service records are kept in memory and will reset when the program is closed. It does not yet have account/password authentication or permanent file/database storage. It does not process payments or send SMS/email notifications.

DATE AND TIME FORMAT
Date: YYYY-MM-DD (example: 2026-12-01)
Time: HH:mm using 24-hour time (example: 09:30 or 14:00)
