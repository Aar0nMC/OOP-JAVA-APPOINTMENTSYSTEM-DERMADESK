

# DermaDesk: Dermatology Clinic Appointment and Service Booking System

## Overview

DermaDesk is a Java-based desktop application designed to simplify appointment scheduling and service booking for dermatology clinics. It provides customers with a convenient way to explore available clinic services, review their prices and estimated durations, and request appointments based on their preferred schedules.

The system also provides clinic staff with tools to manage service information and appointment requests. Staff can review bookings and confirm, reschedule, reject, or cancel appointments. A scheduling conflict checker helps prevent overlapping appointments by considering existing pending, confirmed, and rescheduled bookings.

## Key Features

- **Service Catalog** – Displays available dermatology services, including their descriptions, prices, and estimated durations.
- **Appointment Booking** – Allows customers to select a service and request an appointment based on an available date and time.
- **Appointment Status Tracking** – Enables customers to view the current status of their appointment requests.
- **Appointment Management** – Allows clinic staff to confirm, reschedule, reject, or cancel customer bookings.
- **Schedule Conflict Checking** – Prevents overlapping appointments by checking existing reservations before accepting a requested schedule.
- **Service Management** – Allows authorized staff to maintain the clinic's service list and update service prices.

## Target Users

- **Customers** – Individuals who want to browse dermatology services and schedule clinic appointments.
- **Clinic Owner and Staff** – Personnel responsible for maintaining service information and handling appointment requests.

## Technologies and Concepts

The system will be developed using Java and its object-oriented programming principles.

- Java Swing for the desktop graphical user interface.
- Classes and objects for organizing system components.
- Encapsulation and abstraction for managing data and system operations.
- Methods for implementing system functionalities.
- Arrays or collections for storing and managing records.
- Exception handling for managing invalid inputs and unexpected operations.

## Limitations

- The system does not support online payments or refunds.
- It does not integrate with external appointment booking platforms.
- It does not support multiple clinic branches, rooms, or separate scheduling calendars.
- It does not provide cloud-based or multi-device access.
- It does not send SMS or email notifications.
- It does not provide online consultations, medical records management, or medical diagnosis.
